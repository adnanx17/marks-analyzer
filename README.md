# Marks Analyzer

A simple C++ program that reads marks for multiple subjects and calculates the total, average, highest marks, lowest marks, and letter grade.

## Features

- Stores marks using an array
- Calculates total marks
- Calculates average marks
- Finds the highest mark
- Finds the lowest mark
- Calculates a letter grade
- Rejects marks below 0 or above 100
- Uses separate functions for each calculation
